## Quick Start

### Option 1: Using Node.js (Recommended)

```bash
cd reconstruction/tools
node start-server.js
```

Then open: **http://localhost:8080/reconstruction/phase-01-runtime-analysis/feature-trigger-test.html**

### Option 2: Using PowerShell (Windows)

```powershell
powershell -ExecutionPolicy Bypass -File reconstruction\tools\start-server.ps1
```

Then open: **http://localhost:8080/reconstruction/phase-01-runtime-analysis/feature-trigger-test.html**

## How to Test

1. **Load the page** - Wait 2-3 seconds for the chart to initialize
2. **Verify chart appears** - You should see a TradingView chart widget
3. **Trigger features**:
   - Click **Change Symbol** to change the stock symbol
   - Click **Change Interval** to change time interval
   - Click **Change Theme** to switch themes
   - Click **Change Chart Type** to change visualization
   - Click **Time Scale Scroll** to scroll the time axis
   - Click **Fit Content** to fit all data in view
4. **Export logs**:
   - Click **Export Logs** → Downloads `hook-logs.json`
   - Click **Export Module Map** → Downloads `module-behavior-map.json`

## What Gets Logged

The hook script tracks:

- **Network Requests**: All XHR and fetch calls
- **Script Loads**: Dynamic script injection and loading
- **DOM Elements**: Created elements during initialization
- **Errors**: Window errors and unhandled promise rejections
- **Features**: Which features were triggered and their duration
