PHASE 1: PRE-DEPLOYMENT (2 hours before)

─────────────────────────────────────
☐ Deploy to staging:     npm run deploy:staging:tier-a --verbose

☐ Capture metrics:       npm run metrics:capture:staging-baseline
☐ Team validation:       QA/Product/Ops team approves

PHASE 3: STAGING VALIDATION (24 hours)
───────────────────────────────────────

☐ Team sign-off:         All leaders confirm: GO TO PRODUCTION ✅

↓ IF STABLE FOR 24 HOURS, PROCEED TO PHASE 4 ↓

💡 COMMON ISSUES & QUICK FIXES
═══════════════════════════════════════════════════════════════════════════════════

"Module not loading"
  → Check logs: npm run logs:errors
  → Verify module: npm run verify:module-deployed:MODULE_NAME
  → If unresolved: ROLLBACK

"Performance degraded"
  → Check metrics: npm run metrics:compare:baseline
  → If > 10% slower: Investigate or ROLLBACK
  → Check for memory leak: npm run analyze:memory-usage

"High error rate (> 1%)"
  → View recent errors: npm run logs:errors:last-100
  → If > 5 min persistent: ROLLBACK
  → If intermittent: Monitor and investigate

"Traffic routing issue"
  → Check traffic split: npm run traffic:status
  → Reset if needed: npm run traffic:route:green:0%
  → Contact DevOps immediately
