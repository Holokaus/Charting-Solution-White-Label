# AGENTS.md — TradingView Advanced Charts (White Label)

## Critical Constraints

- **`charting_library/` is read-only.** It contains ~1,750 pre-built, hashed bundle chunks (JS, CSS, fonts, locales). This is a compiled distribution artifact. The library source code is proprietary and NOT in this repository. Do not attempt to refactor, lint, or "fix" files inside this directory.
- **Do not reverse-engineer or reconstruct** the charting engine, drawing tools, studies, or widget internals from the minified bundles. This violates TradingView's license and copyright.

## What Is Safe to Edit

The only editable source code in this repo is the **UDF datafeed adapter**:

- Path: `datafeeds/udf/src/`
- Language: TypeScript
- Build outputs: `lib/` (compiled JS), `dist/bundle.js` (UMD bundle)

## Build Commands (run inside `datafeeds/udf/`)

| Command | What it does |
|---------|--------------|
| `npm install` | Install dependencies (required before first build) |
| `npm run compile` | Compile TypeScript (`src/` → `lib/`) |
| `npm run bundle-js` | Rollup UMD bundle (`lib/` → `dist/bundle.js`) |
| `npm run build` | `compile` + `bundle-js` |
| `ENV=prod npm run build` | Minified production build (default `ENV=development` skips terser) |

## Repo Quirks

- **No root-level scripts.** Root `package.json` exists only for npm metadata and exports. It has no `scripts` field.
- **No lockfiles.** `datafeeds/udf/.npmrc` sets `package-lock=false` and `audit=false`. Do not generate lockfiles here.
- **No test runner, no lint config, no CI workflows.** There are no tests to run.
- **Designed as a git submodule.** Consumers typically include this repo as a submodule in their own projects.

## Entry Points

| Target | Entry |
|--------|-------|

| ESM import | `charting_library/charting_library.esm.js` |

## Where to Look for API Documentation

- Public API types: `charting_library/charting_library.d.ts` (30k+ lines, generated by dts-bundle-generator)
- Online docs: https://www.tradingview.com/charting-library-docs/
- Changelog: `changelog.md` (includes breaking changes and migration notes per version)

## What an Agent Should NOT Guess

- Do not run `npm test`, `npm run lint`, or `npm run typecheck` at the root — they do not exist.
- Do not modify files in `charting_library/` or `datafeeds/udf/lib/` or `datafeeds/udf/dist/`. Those are build artifacts. Only edit `datafeeds/udf/src/`.
- Do not assume the repo is a standard Node.js/web app with a dev server. The demo page is `index.html`, which loads the pre-built library and the bundled UDF feed via plain `<script>` tags.
